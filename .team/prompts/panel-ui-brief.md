# 需求提示词 · container-mesh 组网可视化面板（v1）

> **适用范围（2026-11-12）**：此单只覆盖锚点轻量只读面板，不是完整 App 的实现约束。
> 用户已认可 AI Studio 原型的视觉与交互，完整客户端采用
> [跨平台应用设计](../../docs/architecture/APP-PACKAGING.md)。本单的数据契约仍为设计稿，
> 发布前必须确认真实接口已实现，且成员数据受 R-2.4 的授权边界保护。

> 交付物：**一个单文件 `panel.html`**（HTML+CSS+JS 全内联）。它将被 `go:embed` 进
> Go 二进制、由发现节点（serve-discovery）在 `/panel` 路由直接伺服。你就是这个
> 页面的设计与实现者。

## 1. 产品背景（30 秒版）

**container-mesh**：把散落各处（云服务器/家里/公司/受限容器）的机器组成一张私有
mesh——零 root、零入站端口、无 CA 无云端注册。设备之间点对点 QUIC 直连：传文件、
发消息、执行命令、测延迟。发现节点（锚点）持有成员名册并向所有成员推送成员视图。

这个面板是**网主的驾驶舱**：打开就看到「我的网现在有多少台机器、谁在线、谁是
谁、挂在哪个地址」。它是产品的门面——第一个被截图、被分享的界面。

## 2. 数据契约（唯一数据源，全部真实）

页面每 5 秒轮询同源接口 `GET /api/mesh`，返回：

```json
{
  "account_id": "7ehkextbmg6mgi7n",
  "version": 42,
  "generated_at": "2026-11-13T08:00:05Z",
  "summary": { "members": 5, "online": 4 },
  "members": [
    {
      "device_id": "s4il4v4kkfqj3g7w",
      "online": true,
      "endpoints": ["203.0.113.10:7000", "10.0.0.2:7000"],
      "last_seen": "2026-11-13T07:59:50Z",
      "is_anchor": true
    },
    {
      "device_id": "mcejr4vx42kleiah",
      "online": false,
      "endpoints": [],
      "last_seen": "2026-11-12T19:03:11Z",
      "is_anchor": false
    }
  ]
}
```

字段语义：
- `device_id`：16 字符设备标识（monospace 展示，点击复制）
- `online`：此刻是否可达（有活跃心跳/流）；**offline 成员保留在列表里**（名册
  与存活是两回事——掉线不除名）
- `endpoints`：该设备公告的直连地址；离线成员可能为空数组
- `last_seen`：ISO8601，前端转相对时间（"3 分钟前"）
- `is_anchor`：发现节点自身
- `version`：名册单调版本号，每次变更 +1

请求失败（节点重启/网络断）要有**明确的状态提示**（如顶栏变黄「连接发现节点失
败，重试中…」），恢复后自动回来——不许白屏、不许静默。

## 3. 必备信息层级

1. **首屏大数字**：`online / members`（如 **4 / 5**）——这是整个产品最被关心的
   那个数字：「几张容器成功组网了」
2. 成员表：状态点（在线绿/离线灰）、device_id、端点（可多个，monospace）、
   最后在线相对时间、anchor 徽标
3. 顶栏：产品名、account_id、名册版本、数据时间（`generated_at` 相对化）+ 自动
   刷新指示
4. 空状态（0 成员不可能出现，anchor 至少 1）与 1 成员状态都要好看
5. 可选加分项（不强制）：recent 变化轻提示（version 跳变时标注「名册刚变更」）

## 4. 硬约束（违反即返工）

- **零外部依赖**：无 CDN、无外部字体、无网络图片。页面要在**完全离线的 NAT 容
  器里**打开就完整渲染（图标用内联 SVG，字体用系统栈）
- **无框架、无构建链**：原生 HTML/CSS/JS 单文件，不用 npm/webpack/react——产
  品是单个 Go 二进制，前端必须是零构建产物
- **无假数据**：所有数字来自 `/api/mesh`；开发时可以本地 mock 这个接口，但交付
  的 HTML 里不得内置任何演示数据路径（mock 代码删除或注释）
- 单文件 ≤ 100KB；UTF-8；中文文案（产品用户是中文环境）
- 只读面板：v1 没有任何写操作、没有登录（后续版本可能加 token 门禁，留出顶栏
  位置即可，不用实现）

## 5. 设计方向（给创作留空间，只定气质）

- 气质参考：**基础设施工具的驾驶舱**——暗色为主，数据密度可以高，但首屏大数字
  要有冲击力（它是会被截图发推文的画面）
- 参考气质（不是抄）： Grafana / Vercel dashboard / 飞书状态页 的克制感 +
  终端工具的 monospace 细节
- 在线/离线的视觉语言要一眼可分；离线不是错误，是正常状态（灰而不是红）
- 响应式：桌面优先，手机上表格可横向滚动或折叠

## 6. 验收标准（我会逐条核）

1. 单文件打开即用：`python3 -m http.server` + 一个 mock JSON 即可完整预览
2. 断网→顶栏告警→恢复→自动刷新，全程无白屏
3. 4/5 大数字、成员表、anchor 徽标、相对时间、点击复制 device_id 均可用
4. 零出站请求（浏览器 devtools Network 面板除 `/api/mesh` 外无任何请求）
5. 无障碍底线：颜色对比度足够，键盘可聚焦

- 如有 mock 的 `/api/mesh` 示例 JSON，一并附上（用于我本地核验）
